# Reproducing forward trajectory plots

The script uses final model checkpoints and test interactions. It does not train
models. Existing manuscript figures are not regenerated by editing this script.

Corrections:
- BBDRec's history endpoint is the final valid output of `diffu.ag_encoder`,
  using the same embedding lookup, dropout (in evaluation mode), and history
  mask as model inference.
- Paths use one-step forward transitions with independent innovations. They
  are not curves obtained by reusing a single noise vector in marginal formulas.
- Random streams are reproducible but distinct across datasets, models, and
  samples. Different samples are not forced toward an identical DDPM noise point.
- `m`, step count, and DDPM noise schedules are supplied from actual run settings.
  No visualization-specific small-noise override is retained.

## Inputs and command

Create a YAML mapping with one entry for every requested dataset and model:

```yaml
baby:
  bbdrec:
    diffusion_steps: <actual training value>
    m: <actual training value>
  diffurec:
    diffusion_steps: <actual training value>
    noise_schedule: <actual training value>
  dreamrec:
    diffusion_steps: <actual training value>
    noise_schedule: <actual training value>
```

Replace the placeholders with actual values before use. Include any other
settings that differ from `src/config.yaml` (e.g. architecture, causal mask,
maximum history length). The checkpoint tree is
`MODEL/DATASET/MODEL_DATASET.pth`; Stage-1 checkpoints are not substitutes.

Run from `src/` with the normal project dependencies installed:

```bash
python analysis/trajectory_viz.py --dataset baby \
  --run-configs /path/to/actual_run_configs.yaml \
  --saved-dir /path/to/final_checkpoints
```

The script writes per-model SVGs, `trajectory_data.npz` (high-dimensional states,
2-D coordinates, sampled history/target IDs), and `trajectory_metadata.json`
(point identities, seeds, run settings, and checkpoint paths). All model panels
for a dataset share one t-SNE fit. t-SNE does not by itself establish improved
recommendation accuracy or globally comparable distances between independently
trained embedding spaces.

Numerical checks, requiring only NumPy:

```bash
python -m unittest discover -s tests -p 'test_trajectory_sampling.py' -v
```
